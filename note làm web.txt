## ⚠️ BÀI HỌC KINH NGHIỆM

### 1. Netlify đã đổi chính sách
- Trước: Free không giới hạn deploy
- Nay: 300 credits/tháng → dễ hết
- **→ Vercel/Cloudflare tốt hơn cho dự án học tập**

### 2. `.env` phải nằm trong `.gitignore`
- Nếu không → key bị lộ lên GitHub
- Luôn check trước khi push lần đầu

### 3. Local dev rất quan trọng
- Sửa code GitHub web chậm (1 phút/deploy)
- Local: sửa xong Ctrl+S → thấy ngay
- **→ Nên setup local từ đầu dự án**

### 4. Rate limit email
- Supabase free: 2 emails/giờ (khóa cứng)
- **→ Setup Custom SMTP (Gmail) để tránh**

### 5. Syntax giữa các nền tảng khác nhau
- Netlify Functions: `exports.handler`
- Cloudflare Functions: `export async function onRequest`
- Vercel Functions: `module.exports` hoặc `export default`
